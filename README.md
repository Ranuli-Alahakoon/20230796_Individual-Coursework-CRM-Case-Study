# 20230796_Individual-Coursework-CRM-Case-Study
BI analysis of S&amp;P 500 shares (2021–2024). Clusters shares by risk–return (mean weekly return, weekly beta) and by adapted RFM trading activity (high-volume days, traded value) using Ward and K-means, then compares segments for investment analysts and fintech BI stakeholders. (Python/Colab.)
